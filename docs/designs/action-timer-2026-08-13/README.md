# 吉日タイマー(全体画面) 画面デザイン提案

- 作成日: 2026-08-13
- 対象プラットフォーム: Web(レスポンシブ、320px〜、ビルド工程なしの PWA)
- 想定ユーザー / 主要ユースケース: 個人が「思い立ったこと」を登録し、72時間の導火線が燃え尽きる様子を見て着手を促す。1画面(登録フォーム + 燃えているリスト + 不発弾リスト)の縦スクロール構成。
- 主要制約: 依存ライブラリなし・ビルド工程なしの Vanilla JS(モックアップは単体 HTML として近似実装。実装への直接転用は前提としない)。既存デザインは「現代和風×燃える付箋」の世界観(墨色背景・明朝体見出し・炎色アクセント・燃焼アニメーション)を持つ。**本比較は既存世界観の置き換え検討ではなく、方向性の対比・参考用。**

## 3 案サマリ

| 案 | コンセプト一行 | 強み | 弱み | おすすめ度 |
|----|----------------|------|------|-----------|
| [Material 3](./material-3.md) | Dynamic Color で「炎」の tonal palette を主役に、Expressive なモーションで緊迫感を演出 | 炎の色を Source Color に一元化しやすい、Web 実装が容易 | カードが平坦で「焼け跡・灰化」の質感が弱い、Android 的な印象 | ○ |
| [Fluent 2](./fluent-2.md) | Acrylic / Mica の半透明レイヤーで「灰と煙」の質感を出す落ち着いた案 | 半透明レイヤーが灰化表現と自然に馴染む、High Contrast 標準対応 | 業務系の印象が強い、Reveal はモバイルの hover 無しで機能しにくい | ○ |
| [Liquid Glass](./liquid-glass.md) | ガラス層の下で発光する透明感で「炎の光そのもの」を演出 | 既存の炎メタファーを最も直接的に強化できる、PWA のホーム画面設置と親和性 | Web でのブラウザ差異、装飾過多のリスク、公式仕様一部未確認 | ◎ |

## 推奨

**本命**: Liquid Glass 案の「発光・透明感」というコンセプトを、Fluent 2 の Acrylic/Mica 的な実装アプローチ(`backdrop-filter` ベースで Web でも比較的安定して再現できる)で組む**ハイブリッド**。

**理由**: プラットフォーム制約は「Web PWA・クロスブラウザ・ビルド工程なし」であり、公式ヒューリスティックに従えば M3 寄りが素直だが、この画面の核心は機能性より「燃えている情緒」の表現にある。3 案の中で Liquid Glass のコンセプト(specular highlight による発光、Thin Material による灰化表現)が既存の炎メタファーと最も強く共鳴する一方、Web(特に Android Chrome)での `backdrop-filter` 品質のばらつきと実装コストは無視できない。Fluent 2 の Acrylic/Mica は同じ「半透明レイヤー」の発想をより手堅く Web で再現できるため、意匠の方向性は Liquid Glass、実装の足場は Fluent 2 の考え方、という組み合わせが現実的な落としどころになる。M3 は実装コストが最も低いが、和風×燃焼の世界観からは最も遠い。

**ハイブリッドの可能性**: 燃焼中カードに Liquid Glass の specular highlight(縁の発光)+ 燃焼メーターのグラデーション発光を採用しつつ、レイヤー構造(layer1/layer2 に相当する厚みの差)は Fluent 2 の Acrylic/Mica の考え方に寄せる。不発弾は Thin Material 相当で「霞んだ」表現にし、既存の色褪せた灰の演出を強化する。Corner shape は squircle 寄りの大きめの丸みを採用し、既存の明朝体見出し・和風カラーパレットとは独立して、素材表現のみを部分採用する。
