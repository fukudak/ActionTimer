# 吉日タイマー(全体画面) — 和風×燃焼 深化案

- 作成日: 2026-08-13
- 位置づけ: `README.md` の3案(Material 3 / Fluent 2 / Liquid Glass)は汎用デザインシステムとの対比・参考用。本ドキュメントは、既存の「現代和風×燃える付箋」の世界観([style.css](../../../style.css))を前提に、**汎用システムに寄せず** に「かっこよさ」を深化させる方向を検討する。

現状(2026-08-13時点)の核: 墨色背景 `#0b0a09`、明朝体見出し、炎色アクセント `#c94a32`/`#ffd54a`/`#ff7b1c`、燃える付箋の一行表示(clip-path による焦げ目 + burn-front の発光帯)、燃え尽きアニメーション。この核は変更せず、2方向で「深化」を検討する。

## 方向A: 灯籠(あんどん)案 — 発光を深化する

### コンセプト一行

燃えている項目そのものを紙提灯のように光らせ、緊急度が上がるほど発光が強くなる。不発弾は「消えた提灯」として完全に光を失う。

### 具体的な変更点

- **背景**: 現状の `#0b0a09` をさらに沈める(`#050403` 相当)。SVG フィルタ(`feTurbulence`)による微細な和紙の繊維ノイズを背景に薄く重ね、外部画像なしで質感を出す。
- **燃焼中カード**: 内側に暖色の inset box-shadow を常時薄くかけ、「内側から光っている」質感にする。緊急度が上がるほど発光の強さ・範囲を段階的に増やす(3〜4段階)。
- **燃焼メーター**: 直線プログレスバーを廃し、既存の clip-path 焦げ目をさらにジグザグに強調 + burn-front 周辺に小さな火花パーティクルを 2〜3 点、CSS keyframes で明滅させる。
- **残り時間の数字**: 現状の tabular-nums をより大きく・タイトなトラッキングで際立たせ、視認性と緊迫感を両立する。
- **不発弾セクション**: 全体を現状よりもう一段暗く・低彩度にし、「灯りが消えた区画」として視覚的に分離する。

### 強み・弱み

- **強み**: 既存のビジュアル言語(墨色・炎色・付箋の焦げ目)を一切壊さずに「かっこよさ」を積み増せる。実装は CSS のみで完結し、依存ライブラリなしの方針([design.md](../../design.md))とも整合する。
- **弱み**: 発光表現を強めるほど低スペック端末での描画負荷(box-shadow・blur の多用)が増える。過剰にすると「消えた提灯」の不発弾セクションが単に地味に見えるリスクがあり、不発弾側にも別の求心力(方向B寄りの装飾)を少し足す調整が要る。

## 方向B: 線香花火案 — 緊迫感を深化する(一点豪華主義)

### コンセプト一行

平常時は墨と生成り色だけのミニマルな和風とし、炎色は「本当に緊急な時だけ」爆発的に使う。線香花火の「玉」が小さく縮んでいく様子を燃焼メーターに転写する。

### 具体的な変更点

- **平常時カード**: 炎色を一切使わず、墨色・生成り色(和紙色)のみのモノトーンにする。罫線を細く、余白を広くとり「静」を強調。
- **緊急時(残り時間が閾値未満)のみ**: 炎色のパルスアニメーション + 火花パーティクル(radial-gradient を複数重ね、keyframes でランダムに明滅)を初めて出現させる。「静から動への切り替え」自体を緊急度のシグナルにする。
- **着火ボタン**: 通常時は墨色地に生成り文字のみ。hover / focus で初めて炎色がにじみ出る(現状の常時炎色より抑制的)。
- **燃焼メーター**: 線ではなく「玉」のドット表現にし、時間経過に応じてドットが縮小・減光していく(線香花火の玉が小さくなる様子のメタファー)。

### 強み・弱み

- **強み**: 平常時の情報量を減らし洗練度を上げつつ、緊急時のコントラストが際立つため「見た瞬間に危ない項目がわかる」という本来の目的([CLAUDE.md](../../../CLAUDE.md) の System Intent)と相性が良い。色数を絞ることで「かっこよさ」の質が上がりやすい。
- **弱み**: 平常時にモノトーンへ倒すため、"燃えている"という常時の情緒的手触りは方向Aより弱まる(緊急時にしか炎を感じない)。閾値設計(何%残りで演出を切り替えるか)の調整が難しく、チューニングコストがかかる。

## 比較

| 軸 | 方向A: 灯籠案 | 方向B: 線香花火案 |
|----|--------------|-------------------|
| 常時の情緒 | 強い(常に燃えている実感) | 弱い(平常時はモノトーン) |
| 緊急時のインパクト | 中(段階的に強まる) | 強い(静→動の切り替えで際立つ) |
| 実装コスト | 中(発光・ノイズ表現) | 中(閾値ロジック + パーティクル) |
| 既存資産との親和性 | 非常に高い(現状の延長線) | 高い(配色戦略の変更を伴う) |
| 低スペック端末負荷 | やや高い(常時 glow) | 低い(平常時は装飾なし) |

## 推奨

**本命**: 方向A(灯籠案)をベースに、方向Bの「一点豪華主義」の思想を緊急時演出にのみ部分採用するハイブリッド。

**理由**: CLAUDE.md の System Intent は「通知では急かさない。アプリを開いたときに燃えている導火線を見せることだけで行動を促す」であり、常時の情緒的な燃焼感(方向A)を主軸に保つべきである。一方で、残り時間がわずかな項目は方向Bの「静から動への切り替え」で際立たせると、一覧性を保ちながら本当に危ない項目への注意を強く引ける。両方向とも既存の CSS のみ・依存ライブラリなしの方針([design.md](../../design.md))とそのまま両立する。
